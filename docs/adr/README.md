# Architecture Decision Records

Each file records one significant, cross-cutting decision: the context, the
decision, its consequences, and the alternative we rejected and why. They exist
so a choice made once doesn't have to be re-derived (or accidentally reverted)
later. `docs/feature-contracts/` says *what is true now*; an ADR says *why we
decided it, and what we chose against*.

Numbered, append-only. Supersede rather than edit when a decision changes.
